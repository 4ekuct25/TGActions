## 2026-09-12 — Хаб доступен по локальному адресу, облачный клиент данных не отдаёт

**Что:** работа с хабом переведена на локальный адрес в домашней сети. Оба сценария
перезалиты (настройки 885/885, движок 849/849) и хаб перезагружен — по запросу,
без изменения содержимого.

**Почему:** `web.spruthub.ru` дважды за сессию не поднял канал данных. Картина
обманчивая: страница грузится, имя дома и версии прошивки показаны, ошибок в консоли
нет, статика отдаётся с кодом 200 — но списки сценариев и устройств пустые, а вверху
висит «Подключение к серверу». Выглядит как пустой хаб. Локальный адрес в тот же
момент отдал всё.

**Как проверено:** после перезагрузки хаба в журнале `pollOnce` каждые ~9 секунд
(00:27:02, 00:27:11, 00:27:20, 00:27:29, 00:27:38, 00:27:48), по одному
`scheduleNextPoll` на каждый. Поиск по `409` — пусто; чтобы это не было ложным «ок»
из-за сломанного фильтра, прогнал контрольный запрос `Registered` — нашёл ровно одну
строку «Registered 5 commands for home». Одна регистрация = один экземпляр движка.

**Откат:** н/п, содержимое сценариев не менялось — та же сборка из коммита `b4c9322`.
